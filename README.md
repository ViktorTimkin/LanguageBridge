# Language Bridge

Android-приложение для голосового перевода в реальном времени между русским и армянским языками. Задумано как разговорник для живого общения "лицом к лицу": один человек говорит по-русски, другой — по-армянски, оба видят и слышат перевод сразу.

## Возможности

- Распознавание речи на русском и армянском
- Перевод текста между языками
- Озвучка перевода нейронным голосом
- Режим "лицом к лицу": два независимых чата на экране (верхний перевёрнут на 180° для собеседника напротив), каждый со своей кнопкой записи

## Стек технологий

- **Kotlin** + **Jetpack Compose** — UI и логика
- **Azure AI Speech SDK** — распознавание речи, перевод, синтез речи (Speech-to-Text, Speech Translation, Text-to-Speech)
- **Kotlin coroutines** — асинхронные вызовы к Azure без блокировки интерфейса

## Требования

- Android 12 (API 31) и выше
- Ресурс **Speech** в Azure (портал Microsoft Azure), бесплатного тарифа F0 достаточно для разработки

## Настройка проекта

1. Создать ресурс **Speech** в [Azure Portal](https://portal.azure.com) (издатель — Microsoft).
2. В разделе **Keys and Endpoint** созданного ресурса скопировать ключ и регион.
3. В корне проекта в файле `local.properties` добавить:

   ```properties
   AZURE_SPEECH_KEY=ваш_ключ
   AZURE_SPEECH_REGION=ваш_регион
   ```

4. Синхронизировать и собрать проект (**Build → Rebuild Project**) — значения подтянутся в `BuildConfig`.

`local.properties` не должен попадать в систему контроля версий (уже добавлен в `.gitignore` по умолчанию).
